# Iron Warrant

Original gritty pixel-art action game built with Xbox360 Game Maker.

## Campaign

1. Prison Shower
2. Motel Ambush
3. Cafe Parking Lot
4. House Assault
5. Atlanta Club
6. Final Warehouse

The current playable campaign contains 69 enemies across six long scrolling stages, checkpoints, shooting, melee combat, particles and multi-layer parallax.
